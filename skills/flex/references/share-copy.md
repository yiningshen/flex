# Share copy (`share.md`)

Write the text the maker will paste next to the video. Same truth rules as the video: only claims in `truth.md`.

## Per direction

**Launch** — for X/Bluesky, Hacker News, Product Hunt, LinkedIn, README.
- Post (≤280 chars): the hook + what it is + link. No hashtag soup; one or two at most if the platform rewards it.
- HN title: "Show HN: <Name> – <plain definition>" (no hype words, no emoji).
- Product Hunt tagline (≤60 chars) + 2-sentence description.
- README snippet: the poster image linked to the video, plus a one-line alt text.

**Explain** — for friends, family, community groups, a landing page.
- One short paragraph in everyday words: the problem, what it does, what it costs.
- "Who it's for" line.
- Landing-page caption (≤15 words).

**Use cases** — for the communities the personas belong to (a bakers' forum, a teachers' group).
- One post per persona, in that community's language: "If you take orders by DM, this might save you an evening a week" — only if the product can actually do it (no invented time savings: "might help with…" is fine, "saves 5 hours" isn't unless sourced).

**Setup** — for the README "Getting started" section, a help page, or replying to "how do I install this?".
- The effort card as plain text (same rows, same numbers).
- Link to the written instructions.
- "Stuck? <where to ask>" if the project has a place.

## Always include

- Alt text for the video/poster (what's on screen, ≤125 chars).
- Suggested file names and where the files are (`flex-output/<direction>/<direction>.mp4`, `poster.png`).
- Any ⚠️ items from `truth.md` the maker should confirm before posting.

Write like a person, not an ad: plain verbs, no "excited to announce", no "game-changer", no rocket emoji.
